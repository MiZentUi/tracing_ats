# Выдержки из ТЗ
## Полное описание
Вам необходимо разработать систему, которая сопоставляет резюме кандидата с требованиями конкретных вакансий и формирует структурированную оценку соответствия, подбирая наиболее подходящую вакансию для кандидата.
Решение должно определять совпадения и пробелы по опыту, образованию и навыкам, выделять сильные и слабые стороны кандидата и формировать рекомендации для дальнейшей коммуникации с ним. Оценка должна быть объяснимой и опираться только на информацию из резюме и вакансий.


## Ожидаемый результат работы
Для каждой вакансии таблица требований с полями: требование, подтверждение в резюме, статус соответствия, комментарий.
1. Рейтинг или упорядоченный список вакансий по степени соответствия кандидату.
2.Для каждой вакансии таблица требований с полями: требование, подтверждение в резюме, статус соответствия, комментарий.
3. Статусы должны различать как минимум полное соответствие, частичное соответствие, отсутствие соответствия и ситуацию, когда информация в резюме не указана.
4. Сильные стороны кандидата относительно выбранной вакансии.
5. Пробелы и риски, которые стоит уточнить на следующем этапе.
6. Рекомендации для рекрутера и несколько вопросов кандидату, которые помогут проверить спорные или отсутствующие данные.
