# ADR 0006. Скоринг при загрузке через gRPC scoring-service

- **Статус:** принято
- **Дата:** 2026-11-11
- **Контекст:** `resume-service`, инварианты 1, 4, 5, 8, 9 и 12 (AGENTS.md, раздел 4)
- **Заменяет:** ADR 0002

## Контекст

Предварительный скор раньше считался пакетно в скрининге временным Java-портом.
Это нарушало правило «арифметика только в Python» и задерживало результат до запуска
пакета. Нужно считать `Score_pre` сразу после загрузки и маскировки резюме, а
скрининг должен использовать уже готовые запуски.

Контракт `scoring-service` (`contracts/proto/scoring_service/v1`) считается внешним:
в нём есть только `ScoreResume` с обезличенным текстом и шаблоном. Весов, внешних
фактов и `Refine` в контракте нет.

## Решение

1. После коммита загрузки публикуется `ResumeMaskedEvent`. Отдельный пул
   `scoringExecutor` вызывает `GrpcScoringClient`.
2. `application.status` получает промежуточные значения `SCORING`, `SCORED` и
   `SCORING_FAILED`. `PRELIMINARY`-запуск создаётся с `batch_id = NULL` и
   `template_version`.
3. Скрининг выбирает `SCORED`, `SCORING` и `SCORING_FAILED`, ждёт `SCORING` до
   `ats.screening.scoring-wait`, по дедлайну ставит `FAILED` и считает отклик
   проваленным. Устаревший `PRELIMINARY` пересчитывается по текущей версии шаблона.
4. `DecideScreening` вызывается один раз на пакет. `FINAL` создаётся копированием
   `PRELIMINARY`, без повторного вызова LLM.
5. GitHub вызывается только для `SHORTLISTED` с согласием. Нормализованные факты
   сохраняются в `external_evidence` и показываются в отчёте.

## Последствия

- Java не содержит формул скоринга; `Score` и границы приходят из Python в шкале
  `0..1` и переводятся в `0..100` на границе адаптера.
- Пока в контракте нет `Refine`, `FINAL` равен `PRELIMINARY` по баллу, а GitHub
  не меняет Score. Это ограничение контракта; после расширения контракта FINAL
  будет считать внешние факты отдельным вызовом.
- `score_run` остаётся неизменяемым: пересчёт и FINAL создают новые строки.
- `scoring-service` остаётся stateless и не получает PII, БД, файлы или GitHub.
